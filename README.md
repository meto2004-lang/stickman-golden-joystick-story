# عصا التحكم الذهبية — قصة ستيكمان 🎮✨

قصة ستيكمان متحركة من **جزأين (١٤ مشهداً)** تُعرض في المتصفح، مبنية بـ **React + Vite + TypeScript + Tailwind**.

| الجزء | العنوان | المشاهد | المدة |
|---|---|---|---|
| الأول | عصا التحكم الذهبية | ١–٧ | ٢:٣٧ |
| الثاني | الختم القديم | ٨–١٤ | ٢:٥٢ |
| كاملة | القصة كاملة (للفيديو) | ١٤ | ٥:٤٠ مع المقدمة والفاصل |

## الشخصيات

- 🟦 الأزرق (البطل) · 🟥 الأحمر (الخصم ثم التائب) · 🟨 الأصفر (الصديق) · ⚫ الأسود (حارس الختم)
- ⬛ الحارس الفارغ (كيان الظل — الجزء الثاني)

## التشغيل على الكمبيوتر

### ١) الأسهل: بدون أي تثبيت
افتح الملف **`story.html`** الموجود في جذر المشروع **بضغطة مزدوجة**.
ملف واحد يحتوي كل شيء (الكود + التصميم + الخط) ويعمل بدون إنترنت وبدون Node.

> ⚠️ لا تفتح `index.html` بضغطة مزدوجة: هذا ملف المشروع في وضع التطوير ويحتاج مُشغّل Vite،
> لذلك ستظهر لك رسالة توضّح ذلك. استخدم `story.html` بدلًا منه.

### ٢) للتطوير
```bash
npm install
npm run dev        # التطوير
npm run build      # بناء نسخة الإنتاج في dist/
npm run build:local  # بناء + تحديث story.html (النسخة القابلة للنقل)
npm run preview    # معاينة نسخة الإنتاج
```

### مشاركة النسخة مع الآخرين
بعد `npm run build:local` أرسل ملف `story.html` فقط (≈ ٠.٦ م.ب) عبر واتساب أو غيره،
وسيفتحه المستلم بضغطة مزدوجة في أي متصفح حديث.

## تحويل القصة إلى فيديو (للرفع على يوتيوب) 🎬

اضغط زر **«🎬 فيديو»** في الأعلى (أو الزر الموجود في صفحة الغلاف)، ثم:

1. اختر ما تريد تحويله: **الجزء الأول** أو **الجزء الثاني** أو **القصة كاملة** (الجزءان + فاصل بينهما).
2. اختر الدقة (1080p / 720p / 480p) ومعدل الإطارات (24 / 30 / 60).
3. اختر تفعيل **الموسيقى الخلفية** و**الترجمة المدمجة في الصورة**.
4. اضغط **«ابدأ التحويل»** واترك التبويب مفتوحًا وظاهرًا حتى ينتهي (المدة = مدة الفيديو نفسها).
5. بعد الانتهاء اضغط **«تحميل الفيديو»**، ثم ارفعه على [YouTube Studio](https://studio.youtube.com).
6. في نافذة النتيجة يوجد زر **«نسخ»** للعنوان والوصف (مع فصول الفيديو الزمنية) والوسوم، وزر لتنزيل صورة مصغّرة.

> نصيحة: صدّر كل جزء كفيديو مستقل (٣ دقائق) ليكون مناسبًا ليوتيوب، أو «القصة كاملة» في فيديو واحد (≈ ٥:٤٠).

ملاحظات تقنية:

- الفيديو يُنتج كاملًا داخل المتصفح؛ لا يُرفع أي شيء إلى أي خادم.
- الصيغة المفضّلة **MP4 (H.264 + AAC)**، وإن لم يدعمها المتصفح يُستخدم **WebM (VP9 + Opus)** — ويقبل يوتيوب الصيغتين.
- يضيف التصدير بطاقة بداية (٤ ثوانٍ) وبطاقة نهاية (٤ ثوانٍ)، وفاصلاً (٣.٥ ثانية) عند تصدير الجزأين معًا.
- يعمل بشكل أفضل على Chrome / Edge / Firefox الحديثة (يتطلب `MediaRecorder` + `canvas.captureStream`).
- إذا خرج الملف بصيغة **WebM** فذلك لأن المتصفح لا يدعم تسجيل MP4: يوتيوب يقبلها مباشرة، وتعمل على VLC ومتصفحات كروم/فايرفوكس، لكن مشغّل ويندوز الافتراضي قد لا يفتحها — استخدم Chrome أو Edge لإنتاج MP4.

## القصة

**الجزء الأول (٧ مشاهد):** الاكتشاف ← السباق نحو المعبد ← كمين الأحمر ← المعبد الغامض ← ظهور الأسود ← المعركة النهائية ← النهاية (كسر العصا).

**الجزء الثاني «الختم القديم» (٧ مشاهد):** الشرارة الأخيرة ← أرشيف الأسلاف ← الصدع ← العالم المقلوب ← الحقيقة ← الحارس الفارغ ← الختم من جديد.

> يبقى الأبطال في العالم المقلوب بعد فتح الأحمر للصدع، ويكتشفون أن العصا كانت مفتاحاً لختمٍ قديم،
> فيتحدون لإعادة إغلاقه. والنهاية تُغلق القصة مع همسة تُشير إلى جزء ثالث محتمل 👁️

## تبديل الأجزاء

من صفحة الغلاف اختر تبويب **الجزء الأول / الجزء الثاني**، أو بدّل من شريط الأجزاء أعلى المشغّل.
وعند نهاية الجزء الأول يظهر زر **«التالي: الجزء الثاني»** للانتقال مباشرة.

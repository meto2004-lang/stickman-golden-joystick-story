# عصا التحكم الذهبية — قصة ستيكمان 🎮✨

قصة ستيكمان متحركة تُعرض في المتصفح، مبنية بـ **React + Vite + TypeScript + Tailwind**.

## الشخصيات

- 🟦 الأزرق (البطل) · 🟥 الأحمر (الخصم) · 🟨 الأصفر (الصديق) · ⚫ الأسود (الغامض)

## التشغيل

```bash
npm install
npm run dev      # التطوير
npm run build    # بناء نسخة الإنتاج
npm run preview  # معاينة نسخة الإنتاج
```

## بنية المشروع

```
src/
├── main.tsx        نقطة الدخول
├── App.tsx         الواجهة الرئيسية

├── render.ts       رسم الإطار الكامل (مشهد + بطاقة + ترجمة + مقدمة/نهاية)

├── VideoExport.tsx واجهة نافذة التحويل إلى فيديو
├── music.ts        موسيقى خلفية مُولّدة داخل المتصفح (Web Audio)
├── scenes1.ts      المشاهد ١–٣
├── scenes2.ts      المشاهد ٤–٥
└── scenes3.ts      المشاهد ٦–٧
```

## تحويل القصة إلى فيديو (للرفع على يوتيوب) 🎬

اضغط زر **«🎬 فيديو»** في الأعلى (أو الزر الموجود في صفحة الغلاف)، ثم:

1. اختر الدقة (1080p / 720p / 480p) ومعدل الإطارات (24 / 30 / 60).
2. اختر تفعيل **الموسيقى الخلفية** و**الترجمة المدمجة في الصورة**.
3. اضغط **«ابدأ التحويل»** واترك التبويب مفتوحًا وظاهرًا حتى ينتهي (المدة = مدة الفيديو نفسها، ≈ 2:45).
4. بعد الانتهاء اضغط **«تحميل الفيديو»**، ثم ارفعه على [YouTube Studio](https://studio.youtube.com).
5. في نافذة النتيجة يوجد زر **«نسخ»** للعنوان والوصف (مع فصول الفيديو الزمنية) والوسوم.

ملاحظات تقنية:

- الفيديو يُنتج كاملًا داخل المتصفح؛ لا يُرفع أي شيء إلى أي خادم.
- الصيغة المفضّلة **MP4 (H.264 + AAC)**، وإن لم يدعمها المتصفح يُستخدم **WebM (VP9 + Opus)** — ويقبل يوتيوب الصيغتين.
- يضيف التصدير بطاقة بداية (٤ ثوانٍ) وبطاقة نهاية (٤ ثوانٍ)، وتبلغ مدة الفيديو الكاملة **2:45**.
- يعمل بشكل أفضل على Chrome / Edge / Firefox الحديثة (يتطلب `MediaRecorder` + `canvas.captureStream`).
